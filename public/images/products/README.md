# Photos Produits ORSAP - Option 1 (Code Article SKU)

Déposez directement vos photos de produits dans ce dossier.

### 📋 Format des noms de fichiers :
Nommez chaque image avec le **code référence article exact** (avec ou sans préfixe "OR") :
- `OR120280.jpg` ou `OR120280.webp` ou `OR120280.png`
- `OR52491.jpg`
- `DE7033.jpg`

### 🔍 Résolution automatique :
1. Le catalogue vérifie en priorité la présence du fichier `public/images/products/[CODE].jpg` (ou `.webp` / `.png`).
2. Dès que vous déposez une photo, elle apparaît automatiquement pour ce produit dans la liste et dans la fenêtre de zoom.
3. Si un article n'a pas encore sa photo déposée, le catalogue affiche automatiquement la photo studio fond blanc correspondante.
